# Data Mining Platform Dashboards

## 1. Purpose

The platform provides three role-based dashboards:

- **User Dashboard** --- personal reading activity, interests, and
    recommendations.
- **Author Dashboard** --- content performance, audience insights, and
    publishing analytics.
- **Admin Dashboard** --- complete platform analytics, data mining
    results, predictions, and anomaly detection.

The main idea is to make ordinary statistics support the data mining
layer rather than making the dashboard only a collection of counters.

------------------------------------------------------------------------

## 2. User Dashboard

### 2.1 My Reading

Display the user's personal activity:

- Books read
- Books downloaded
- Liked books
- Average rating given
- Reading activity / reading time

## 2.2 My Interests

Show the user's most important book categories based on reading and
interaction behavior.

Example:

- Programming --- 42%
- Artificial Intelligence --- 28%
- Business --- 16%
- Psychology --- 10%
- Other --- 4%

This can be calculated from reading, downloads, likes, and ratings.

### 2.3 Recommendations

#### Recommended Books

Recommend books based on the user's behavior.

Possible approaches:

- Collaborative Filtering
- Content-Based Filtering
- User/item similarity

#### Recommended Articles

Use the same concept for articles.

## 2.4 Because You Read

Show recommendations based on books the user has already read.

Example:

> Because you read **Clean Code**

Recommended:

- Design Patterns
- Refactoring
- The Pragmatic Programmer

This can be powered by **Association Rule Mining / Apriori**.

## 2.5 User Segment

Show the user's behavioral segment generated by **K-Means Clustering**.

Example:

> **Active Reader**

Possible segments:

- Casual Reader
- Active Reader
- Book Enthusiast

The segment can be based on:

- Number of books read
- Downloads
- Likes
- Ratings
- Comments
- Reading frequency

## 6. Book Data Mining

### 6.1 Top Books

Display:

- Top 5 most downloaded books
- Top 5 most read books
- Top 5 most liked books
- Top 5 highest-rated books

For ratings, display both:

- Average rating
- Number of ratings

This prevents a book with one 5-star rating from automatically appearing
as the best-rated book.

### 6.2 Frequently Read Together --- Apriori

Discover books that users frequently read together.

Example:

``` text
Clean Code → Design Patterns

Support: 12.4%
Confidence: 78.2%
Lift: 2.31
```

Important metrics:

- Support
- Confidence
- Lift

This can later support the recommendation system.

### 6.3 Category Associations

Discover relationships between book categories.

Example:

``` text
Programming → Artificial Intelligence

Confidence: 72%
Lift: 1.9
```

This helps identify combinations of interests.


Possible algorithms:

- Isolation Forest
- Distance-based anomaly detection
- Clustering-based anomaly detection

Admin can see:

- Suspicious user
- Detected behavior
- Anomaly score
- Relevant activity

## 13. Core Data Mining Algorithms

The project does not need to implement every possible algorithm.

A strong and manageable implementation can focus on four main
algorithms:

### 13.1 K-Means Clustering

**Purpose:** User segmentation.

Input:

- Reading behavior
- Downloads
- Likes
- Ratings
- Comments

Output:

- User clusters

### 13.2 Apriori

**Purpose:** Discover relationships between books and categories.

Input:

- User reading transactions

Output:

- Association rules
- Support
- Confidence
- Lift

### 13.3 Collaborative Filtering

**Purpose:** Personalized recommendations.

Input:

- User-book interactions

Output:

- Recommended books/articles

### 13.4 Decision Tree / Random Forest

**Purpose:** Prediction.

Possible target:

- Whether a user will read a book
- Whether a user will interact with content

## 14. Important Design Principle

The dashboard should not be presented as only a collection of
statistics.

The architecture should be:

``` text
Raw Platform Data
        ↓
Data Collection
        ↓
Data Preprocessing
        ↓
Feature Engineering
        ↓
Data Mining Algorithms
        ↓
Mining Results
        ↓
Dashboard / Recommendations / Insights
```

Ordinary statistics such as:

- Most downloaded books
- Most viewed articles
- Number of users
- Number of books

are useful as supporting analytics.

The main academic value comes from:

- Clustering
- Association Rule Mining
- Recommendation
- Classification / Prediction
- Anomaly Detection

This makes the platform both a useful product and a clear **Data Mining
project**.
